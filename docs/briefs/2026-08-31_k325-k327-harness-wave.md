## What changed

1. **Security-agent SLR (K325, Cybersec-primary steal)** — 72-page systematic literature review of 100 papers (2023–2026). CCC steal: agents are built to **act** (91% modular, 88% planner-and-actor, 95% fully autonomous) but not to be **bounded** (15% critic/verifier, 13% guardrail, 13% human review) or **audited** (11% hallucination rate, 5% scope containment, 1% tool-call accuracy). CCC: keep HITL on irreversible tools (K239); eval = evidence tree not scalar (K289); evidence-ledger discipline (K277). Short source + one concept — no survey dump. `wont_wire`.
2. **Recognition Without Enforcement (K326, ADOPT policy)** — model self-arbitration is a **capability, not a security boundary**. Models decode source-format markers (97.5–100%) and verbalize forged authority yet still act under permissive configs (98.7% detect / 99.3% execute). Fleet-mean execution under novel spoofs is **1.21% [0.5–2.1%]** but concentrated in reproducible cells and shifts **up to 47pp** across deployment windows; restrictive policy eliminates execution on the same weights. **External reference monitor**: authenticated source routing (HMAC-SHA256, deterministic under EUF-CMA; 0/900 test cases; 452/452 replays rejected) + capability-gated tool execution (fail-closed external layer). Residual boundary: **semantic authorization** (confused deputy). `policy_wired`. **Zero attack text. No InstructionArbitrationBench clone (no SPDX).**
3. **Logos (K327, ADOPT policy)** — plugin = **process** on a ROS-like cross-process bus; only shared state = **append-only transcript**; resume with **no repeated effect** after kills at the four tool-call-cycle boundaries (80/80 sessions; one fault ends at one node vs single-process SPOF). No public SPDX → policy only, no clone. Runtime `wont_wire` — do not replace Cursor/`/route`. Pairs K282 AgentRewind, K239 execution fidelity.
