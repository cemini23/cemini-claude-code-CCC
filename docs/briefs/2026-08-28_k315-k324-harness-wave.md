# K315–K324 harness wave — brief (CCC docs)

Date: 2026-08-28 · Wiki: ccc-wiki · Executor: claude-ds Flash · SIP: `wiki/briefs/2026-08-28_ccc-k315-k324-sip-ready.md`

## What changed

Ten arXiv ingests (2608.24957…2608.27439) wired as policy/reference on the harness, plus two operator-approved K311/K312 leftovers shipped as federation skills.

1. **ToolMinimize arg rewriting (K315, ADOPT policy)** — allow/block decides *whether* a call happens; it never rewrites *what data* the tool receives. 81–88% of tool calls over-share PSD under default prompts; privacy prompts leave 36–76%. Middleware rewrite (removal / generalization / substitution / truncation, schema-aware) cuts privacy cost 81.2–92.0% at 100% argument-level validity, 1.77 ms median. PII detectors miss implicit PSD. No public SPDX → policy only.
2. **LifePlanner (K316, OOD)** — geo-spatial + social-media MCP bench; Pass Rate 40.2% on complex planning; failures = incomplete evidence acquisition + imprecise tool use + weak constraint integration, not model size. Short stub, `wont_wire`.
3. **TAU-Agent (K317, OOD)** — traffic-video RAG; central retrieval agent selects evidence (caption + tracking) then VLM. MIT repo, clone skipped. Short stub, `wont_wire`.
4. **ProgRouter (K318, ADOPT policy)** — one-shot cascade routing fails multi-step workflows; route **per step** from a multi-view progress scorer (outcome regimes + subtask completion + progress trends + state quality) + meta-gating under time/cost budgets. Pairs `/route`. No public SPDX → policy.
5. **AsymSpec (K319, WATCH)** — serving-side context-asymmetric speculative decoding (drafter full, verifier compressed; δ-fusion); ≈90% accuracy at 1.3–1.7× throughput / 0.2–0.3× compute. Huawei. `wont_wire`.
6. **Claude Code Complete User Handbook (K320, ADOPT reference)** — Soldani v1.0, 208 pages; source page + **delta** on `entities/tools/claude-code.md`: 4-layer control stack (only 2–4 constrain), plan-as-contract (8-point), measure `/usage` vs `/context` separately, completion-report discipline, Evidence-Gated Delivery, 21 misconception corrections. `[TENTATIVE]` vs Anthropic docs.
7. **ASIL (K321, ADOPT policy)** — JSON structured observations + code-executable semantic actions over screenshot-click; ASIL >80 at <5 actions/task vs 6.6/26.6 screenshot-click strict. Deepest feasible access path per app. No SPDX hit → policy; GUI runtime `wont_wire` (keep cursor-ide-browser; no CUA).
8. **MoRe (K322, WATCH)** — query-aware fusion of role steering vectors: MAS-level quality at **20× lower token cost**. Do not auto-spawn N agents for multi-perspective work. GRPO `wont_wire`.
9. **INTENT-AS-A-TOOL (K323, ADOPT policy + MIT REFERENCE clone)** — intent-targeted tools give a judge-free commitment signal (call probability); complements CoT monitoring, expands labels into dense trajectories, identifies intervention steps. `RebeccaZhang22/intent-as-a-tool` MIT, 17MB clone → `.local/adopts/intent-as-a-tool`. Runtime `wont_wire`.
10. **RedEvoAgent (K324, Cybersec-primary)** — CCC steal is the **validation ratchet**: keep skill updates only when validation improves; never auto-evolve `.cursor/skills`. No attack-skill clone, no PoCs.
